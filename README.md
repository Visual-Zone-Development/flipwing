# Flipwing

Slide your thumb to weave a starship through an asteroid stream and tap to flip its colour through matching energy gates. Build a streak for a bigger multiplier, flip at the last moment for bonus points, and collect stars to charge a shield and buy new ship colours.

## Play

- **PushPlay (Steam Deck, Legion Go, PC):** follow the account that owns this repo in PushPlay (Add game → Follow a GitHub account), or find it on the Discover tab once it's listed. Every push to `main` builds and publishes it.
- **Browser:** `npm run setup`, then `npm run dev` (http://localhost:5173).
